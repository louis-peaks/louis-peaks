Three steps to put it online

01 · UnzipKeep this folder structure together. Read README.md for the file map and editing examples.
02 · Put the source on GitHubUpload the contents of this folder into the repository root. You can leave out dist: Cloudflare rebuilds it.
03 · Connect Cloudflare PagesUse Git integration, select your repository, and enter the settings below.
FrameworkNone
Production branchmain
Build commandnode scripts/build.mjs
Output folderdist

The step-by-step setup is in docs/CLOUDFLARE.md. Adding a post, editing text and replacing pictures are explained in docs/EDITING.md.

Your editing rhythm

Edit the source → commit to GitHub → Cloudflare builds and publishes. If you’re working locally, run node scripts/build.mjs after edits and then reopen the preview. Never make your permanent edits in dist/: that folder is regenerated.

The example stories are labelled in the website. Replace them with your real stories or set draft to true in their JSON settings. Your public email and exact 2027 race date are still to be filled in.

This is the offline guide for the project. It is outside the published dist folder. Markdown guides open as text in some browsers and display with formatting on GitHub.
